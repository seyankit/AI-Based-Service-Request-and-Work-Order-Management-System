Responsible AI Assistance

AI supports decisions without replacing authorized personnel.

This static demonstration uses local JavaScript rules to illustrate advisory category, priority, and duplicate suggestions. The deployed application performs the authoritative workflow and persistence.

✓

AI recommendations are advisory only. The final category, priority, approval, and work assignment are decided by authorized Holy Trinity College personnel.

01

Classification

Suggests the most likely service category from the request description.

02

Priority

Suggests urgency based on impact and safety-related keywords.

03

Duplicate Check

Highlights similar sample requests for authorized human review.

04

Service Insights

Summarizes service operations for administrator review.

Service Workflow

From request submission to verified resolution

Each stage has a responsible role and a corresponding system record.

  1. 01Requester

    Submit

    Enter a concern and receive a generated Service Request ID.

  2. 02AI + Administrator

    Review

    Inspect suggested category, priority, and possible duplicates.

  3. 03Department Head

    Approve

    Approve or reject requests requiring authorization.

  4. 04Administrator

    Assign

    Create a work order and assign service personnel.

  5. 05Technician

    Resolve

    Record actions, materials, progress, and completion.
