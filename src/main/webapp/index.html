AI-Assisted Request Management

Smarter request review with human oversight.

AI-assisted analysis helps authorized personnel review service requests more efficiently by recommending categories, priority levels, and potentially related requests.

✓

AI recommendations are advisory only. The final category, priority, approval, and work assignment are decided by authorized Holy Trinity College personnel.

01

Request Classification

Recommends the most appropriate service category based on the submitted concern.

02

Priority Recommendation

Evaluates request details to recommend an appropriate urgency level.

03

Related Request Detection

Identifies potentially similar or duplicate requests for review.

04

Service Insights

Supports request monitoring and service-management analysis.

Service Workflow

From request submission to verified resolution

Each stage has a responsible role and a corresponding system record.

  1. 01Requester

    Submit

    Enter a concern and receive a generated Service Request ID.

  2. 02AI + Administrator

    Review

    Inspect suggested category, priority, and possible duplicates.

  3. 03Department Head

    Approve

    Approve or reject requests requiring authorization.

  4. 04Administrator

    Assign

    Create a work order and assign service personnel.

  5. 05Technician

    Resolve

    Record actions, materials, progress, and completion.
