AI-Based Service Request and Work Order Management System
Holy Trinity College of General Santos City

This project is an initial web interface prototype for the proposed AI-Based Service Request and Work Order Management System of Holy Trinity College of General Santos City.

Purpose

The proposed system aims to organize and manage school service requests and work orders through a centralized platform.

Initial Features
Service Request Management
Work Order Management
AI-Assisted Request Classification
AI-Assisted Priority Recommendation
Duplicate Request Detection
Request Status Monitoring
Service Reports
